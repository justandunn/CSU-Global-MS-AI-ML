## Purpose

This redo aligns the Module 5 Portfolio Milestone with the dataset strategy selected in the Module 4 Portfolio Milestone. The chatbot use case remains a business-safe customer-service routing and retrieval system.

## Module 4 Dataset Strategy

The Module 4 PM selected a hybrid data plan:

- RSiCS: customer-service language patterns and relational phrasing.
- WikiQA: answer-selection and no-answer threshold testing.
- Custom enterprise FAQ/SOP corpus: final domain-specific knowledge base with route labels and approved answers.

The first Module 5 training run uses the custom FAQ/SOP corpus because it contains the route labels and approved answer fields needed for a controlled first training pass. RSiCS and WikiQA remain planned supplemental datasets for later validation.

## Dataset

Generated dataset:

`data/custom_enterprise_faq_sop_corpus.csv`

The corpus contains:

- 80 sanitized coursework FAQ/SOP entries.
- 10 route labels.
- Sample customer questions.
- Curated keywords.
- Approved answer text.
- Source category and source note fields.

The dataset is generated by:

`build_custom_faq_sop_corpus.py`

No private company data is used.

## Model

The model is a dependency-free TF-IDF cosine-similarity retrieval baseline implemented in:

`train_retrieval_chatbot.py`

Final hyperparameters:

- Random seed: 525
- Held-out source-group ratio: 0.40
- Training text column: `combined_text`
- N-gram range: 1-1
- Max features: 2,500
- Draft similarity threshold: 0.20

Final result:

- Train rows: 50
- Test rows: 30
- Accuracy: 1.0000
- Macro F1: 1.0000
- Mean similarity: 0.7323

The report notes that question-only retrieval was much weaker, with the best question-only sweep reaching 0.2333 accuracy and 0.2094 macro F1. This is important because it shows why curated FAQ/SOP metadata is useful and why RSiCS/WikiQA should still be used for later testing.

## How to Reproduce

From the `CSC525` course folder:

```powershell
python MOD5\PM\build_custom_faq_sop_corpus.py

python MOD5\PM\train_retrieval_chatbot.py `
  --input MOD5\PM\data\custom_enterprise_faq_sop_corpus.csv `
  --output-dir MOD5\PM\outputs `
  --text-column combined_text `
  --label-column route_label `
  --group-column source_row_id `
  --seed 525 `
  --test-group-ratio 0.40 `
  --ngram-min 1 `
  --ngram-max 1 `
  --max-features 2500 `
  --similarity-threshold 0.20
```
