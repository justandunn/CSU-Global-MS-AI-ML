# CSC525 Module 3 Critical Thinking Project

Option selected: Option 2, Simple Polynomial Regression in Python.

## Files

- `module3_polynomial_regression.py`: Executable Python script.
- `data/years_experience_salary.csv`: Input dataset used by the script.
- `report/module3_ctp_report.pdf`: Brief APA-style PDF report with output image and figures.
- `outputs/console_output_screenshot.png`: Screenshot-style image of the script output.
- `outputs/polynomial_regression_fit.png`: Regression fit visualization generated by the script.
- `outputs/code_excerpt_screenshot.png`: Code evidence image included in the report.

## Run Command

From this folder:

```powershell
python .\module3_polynomial_regression.py
```

If the default Python environment has dependency issues, use a Python environment with `numpy` and `Pillow` installed.
