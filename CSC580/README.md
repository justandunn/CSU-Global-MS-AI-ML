# CSC580-1: Applying Machine Learning and Neural Networks

Fall 2026, 8-Week Session A

This workspace keeps weekly coursework reusable for the Module 8 Portfolio Project. Source code, generated evidence, written analysis, and submission packages remain separate so every result can be reproduced and audited.

## Working structure

- `COURSE_WORKFLOW.md` — capstone-oriented plan for Modules 1–8.
- `CAPSTONE/README.md` — final-project options, recommendation, evidence standards, and packaging checklist.
- `MOD1/README.md` — exact Module 1 deliverables and execution checklist.
- `MOD2` through `MOD8` — weekly workspaces added as assignments are unlocked and reviewed.

## Standard module folders

Each module should use only the folders it needs:

```text
MODn/
  discussion/
  critical-thinking/
    src/
    inputs/
    outputs/
    screenshots/
    report/
  portfolio/
  references/
```

Do not overwrite inputs. Generated artifacts belong under `outputs/` or `screenshots/`. Zip archives should be built only after the source, output, and report checklists pass.
